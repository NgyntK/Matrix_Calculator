# Matrix_Calculator
A Python-based project for performing mathematical matrix operations.

## About the project

MatrixToolkit is a personal project developed in Python to practice programming, algorithms and linear algebra.
The goal is to create a program capable of performing various matrix calculations through custom implementations.

## Features

- [ ] Matrix addition
- [ ] Matrix subtraction
- [ ] Matrix multiplication
- [ ] Matrix transpose
- [ ] Determinant calculation
- [ ] Matrix inverse
- [ ] Matrix rank calculation
- [ ] Linear system solving


## 📚 Learning objectives

- Improve Python programming skills.
- Understand and implement linear algebra algorithms.
- Practice algorithmic thinking.
- Learn project organization and version control with Git.
